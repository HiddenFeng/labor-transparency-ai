# v0.5 交付与验收：公开资料研究及可恢复发布

日期：2026-09-14。状态：本地开发候选。代码工作位置为当前会话v0.4交付包的独立副本，不是用户Mac。未完成全平台生产验收，未推送GitHub、未部署ChatGPT Sites。

## 这次真正向前推进的内容

在既有“公司登记—资料包导入—发布”基础上，加入可执行的公开来源适配器、持久研究任务、主体核对、冻结草稿复核和可恢复发布。前台能看到真实的处理状态；运营通过独立页面发起一次有限查询、确认候选主体、核对来源及范围、批准本版。公开资料未完成仍不阻止已开放的E0讨论和社区共建。

GLEIF适配器及字段处理已实现，但真实联网检验未通过；不能称为真实企业自动研究已经端到端验证。它只处理企业参考记录和部分会计合并母公司，不负责填造产品、供应链、劳动条件或申诉渠道。来源与上游许可保留到条目；不从登记信息推导高证据劳动好评，也不自动进入公益数据镜像。

## 修复的实质问题

旧版到点没有资料时会生成SOURCE_UNAVAILABLE并结束该任务，后续数据恢复无法自然补齐。本版把对外延期进度与后台任务生命期分开，保留历史积压、重试和恢复；旧空资料快照不覆盖，恢复后发布明确修订。

真实企业不能再直接向旧入口传入自行填写APPROVED的研究包。来源只生成草稿，批准依赖冻结版本和运营五项复核；变更或伪造版本摘要会被拒绝。原PREPARED真实任务迁移到新核对路径，不能利用历史状态绕过。

来源限流、网络失败、超时和访问拒绝分开处理；限流遵守Retry-After并暂停同来源后续任务，可选关系查询遇限流不继续请求。进程中断有租约回收与过期结果隔离。未到期不发布；重复发布不产生额外快照。

## 与最终目的的距离

基础能力已得到重复验证：持久任务、来源字段提取、主体核对、逐版复核、部分发布与失败恢复。真实外部资料链路、长期调度、浏览器体验和生产级运行尚未得到证明。下一步应优先在在线、被允许的本地环境拿到真实接口响应和真实浏览器证据，而不是继续堆相同的模拟测试。

全项目仍有其他未完成项：真实申诉渠道与受控外部提交、模型辅助完整接通、生产身份认证与反滥用、公开附件扫描与脱敏、密钥管理、备份恢复与容量、法律隐私及运营责任核查。结构化申诉模板不能冒充法律Agent已完成。只有所有发布门满足后，才进入GitHub、Sites、服务器和域名的正式发布。
