# v0.5：公开资料研究、复核与可恢复发布

日期：2026-09-14。定位：v0.4的增量实现，不替换公益方向、社区共建或证据规则。本版本是本地开发候选，不是生产上线版本。

## 用户能得到什么

登记实际公司的公开名称和地区后，立即得到公司空间、登记回执和更新目标。公开资料整理、主体消歧、复核、公布和延期分别有状态。资料仍然空白时，已开放的讨论、共建和其他功能继续可用；私人申诉不是查询企业资料的前置要求。

本版仅实现GLEIF企业参考资料适配器及其有限执行器。默认不开网络，不自动运行模型，不启动AgentDock、子Agent、常驻进程或定时任务。公众读取页面不能触发外部查询。运营需要明确授权一次查询，并在逐项核对后批准本版草稿。V0.5没有实现“所有公司明天就能获得完整产品和供应链”的保证。

## 正常路径

登记公司 → 持久队列 → 有限查询 → 主体候选或资料草稿 → 运营核对 → 冻结批准版本 → 到期在本地应用发布 → 原公司页面回查。发布指本地应用生成资料快照，不是上传GitHub或部署ChatGPT Sites。

仅有公司名时，即使检索只返回一个候选，也不自动合并。运营核对来源中的名称、国家/地区、标识后选择候选；下一次查询读取该主体。含LEI的登记需要名称、国家代码和来源匹配；不匹配仍进入主体核对。LEI不是个人证件；登记时没有LEI也可开始。

草稿必须有内容哈希。批准请求携带原哈希，以及主体、出处、范围、隐私、许可五项实际核对记录。草稿变化则拒绝沿用批准。采集器不能自批，也不能给真实公司自行填写APPROVED后直接通过旧的导入接口发布。这里的软件校验只证明流程条件满足，不证明运营人员真的履行了线下核验；生产环境仍需独立角色和审计。

## 来源能支持什么

适配器提取法律名称、LEI、国家/地区、法律辖区、来源中的实体状态和LEI维护状态，并尝试读取直接/最终会计合并母公司。每项保留来源地址、获取日期、内容指纹、字段路径、原始许可及支持范围。

它不提供企业全部产品、实际用工制度、完整股权、交易关系、供应链或具体申诉渠道。这些栏目保留未知，继续由社区贡献或后续授权来源补齐。“未查到”不能写成“没有”，登记状态不能升级为劳动条件或产品质量认证。GLEIF直接/最终母公司关系是会计合并口径，不等于所有股权或供应关系。[S3]

GLEIF开放数据使用CC0；本项目自有代码和贡献的公益用途约束不改变上游已有许可，不声称可以禁止他人按原有权利使用上游CC0数据。[S2] 本版来源草稿不会自动进入社区的安全再分发包；原有授权与公开审批保持独立。

## 失败、延迟与恢复

网络、服务不可用和限流被分类处理。每项任务默认最多3次尝试，指数退避，遵守Retry-After；限流会暂停该来源的后续批次。明确的访问拒绝不自动反复重试该任务。最终失败需运营记录原因后明确重新排队。

任务被持久保存，不仅扫描最近24小时。已结束自然日的新任务和历史积压按到期顺序处理；可用include-current明确进行当天即查测试。每次查询有公司数、请求数、总时间和响应体大小上限。每项最多6个请求，每批默认5家公司；日配额默认120个预留请求。缓存命中也占预留额，是保守成本上限而非精确计费。

执行中的任务带3分钟租约和唯一令牌。进程中断后，下次执行会回收过期租约；旧进程迟到的结果不能覆盖新结果。默认重试上限仍适用，恢复不会无限重置次数。来源要求暂停时不继续请求其余可选关系；已取得的主体资料可以形成注明缺口的草稿。

旧版本到点生成SOURCE_UNAVAILABLE快照后会结束该任务，导致资料后来恢复也不能补齐。本版将真实公开公司转到独立持久队列：没有资料时显示延期，不消费任务；旧的空资料快照保留历史，恢复后以明确的新修订公布。旧的PREPARED真实资料也不能绕过新复核路径。

## 公布时间

保留自然日批次及可配置公布时点，示例默认Asia/Tokyo次日09:00。这不是承诺提交后24小时以内完成，也不是已经安装的调度。未核对资料不能仅因到点就被当作事实发布。界面显示目标、当前进度及逾期，已公开旧资料的时间不自动刷新。

## 隐私与运行范围

来源请求只使用公开企业名称、地区或LEI，不包含请求人、关注原因、私密案件、原始附件或用户自填网址。真实公司登记仅限明确选为公开的企业资料；默认体验模式仍限定虚构数据。真实劳动争议和身份资料仍不应输入本开发环境。

公开投影排除街道、联系方式及自然人主体。为核对响应及避免重复查询，来源原始JSON暂存在运行数据库中，可能包含来源原有的地址等字段：默认24小时可用缓存、写入时清理超过48小时的缓存。这不是即时删除保证；管理员应在退出运行和备份轮换时处理遗留缓存。原始缓存不进入静态站、源码包或公益分类导出。SQLite文件和已有证据密钥均属运行资料，不能提交Git。

## 当前证据及边界

源字段提取和业务链路使用明确标记的模拟GLEIF响应验证，测试中的复核并非真实企业调查。当前运行环境的真实GET检查返回SOURCE_NETWORK_ERROR，未获得真实接口响应；因此实际字段兼容性、企业覆盖、完整成功链路仍待正常网络环境检验。不得把官方网页可读、HTTP本机检查通过或模板输出视为真实接口接入成功。

实际浏览器正常导航返回ERR_BLOCKED_BY_ADMINISTRATOR，之后停止；没有改走其他路径绕过，也没有截图、视觉、手机布局或点击验收结论。
