# CHANGE v0.7.1 — 匿名辅导/代办与每日 Agent 处理

ID: `LTP-V071-ANON-ADVISORY`

PROBLEM

v0.7.0-rc.1 明确不提供私信或私密申诉入口。用户现在要求新增一个匿名辅导/代办入口：允许用户在系统引导下提交不含身份和敏感个人信息的劳动问题，后台持久保存；项目 Agent 每日固定时间读取待办，为每个匿名回执生成私有建议，并仅向公众发布聚合数量/类别等日报。

CURRENT

- Sites 候选有公司/社区/贡献/审核/纠错/再分发闭环。
- 没有匿名辅导队列、匿名回执、个人建议或公开聚合日报。
- 当前明确拒绝真实私密申诉、身份证明、敏感附件、健康/支付信息和私人联系方式。
- 自动公司资料研究在 Python 基线中已有有限 GLEIF 队列/调度/人工复核/发布流程，但仅覆盖法律实体参考与会计合并母公司，不覆盖全部产品、厂区、供应链或劳动实践来源。

PROPOSED

新增“匿名辅导/代办”能力，但不把它升级成“私密信息服务”或“正式申诉代理”：

1. 用户提交结构化、非敏感问题；不接收姓名、私人联系方式、证件号、精确住址、健康/支付信息或附件。
2. 服务生成高熵匿名回执码；数据库只存回执哈希，不存明文回执码。
3. 同一浏览器匿名会话可查看自己的记录；遗失会话后可用回执码恢复查看。
4. Agent 运营凭据只能读取待处理匿名记录的必要字段并写入建议；普通用户不能读取他人记录。
5. 每日处理生成私有个案建议，以及只含数量、类别、处理状态的公开日报；公开日报绝不包含个案正文、回执码、公司ID或可识别细节。
6. 前端明确说明：当前不提供真实私密信息/材料服务；如需全自动跟进需另行联系项目方，但当前站点不收集联系方式，也不虚构外部联系渠道。
7. 增加固定时刻 Agent runner 接口/脚本，支持一次处理和定时循环；Sites 部署时映射到平台可用的调度方式。

ADDED

- 匿名辅导数据模型、私有建议、公开日报模型。
- 匿名回执访问接口。
- Agent 待办读取、建议写入、日报生成接口。
- 每日 runner / scheduler 入口。
- 前端匿名辅导提交、回执保存、建议查询、公开日报展示。
- 完整用户循环与持久化/权限/隐私测试。

MODIFIED

- `sites-app` 状态 schema 从 0.7 扩展为 0.7.1 兼容字段。
- `/api/config` 能力表增加匿名辅导，但继续声明附件、真实私密材料服务关闭。
- Sites 交接文档增加数据库、运营身份、定时任务映射要求。
- v0.7 完整流程审计增加公司自动研究覆盖矩阵。

REMOVED

无。不会删除现有 v0.7.0-rc.1 公开交互能力，也不会删除 Python v0.6.1 基线。

PRESERVED_CAPABILITIES

- E0 正常公开传播；热度与证据等级分离。
- 公司、产品、劳动实践证据范围分离。
- 贡献修改回 E0、纠错暂停高证据展示/再分发、撤回不继续公开。
- 证据审核与再分发审核相互独立。
- 不伪造外部机构受理、法律结论或数据来源。
- 不把匿名辅导内容公开为社区事实或公司证据。

AFFECTED_CONTRACTS

- `sites-app/src/server.mjs`

ALTERNATIVES_CONSIDERED

1. 直接开放自由私信/附件：拒绝。当前尚无足够私密信息处理协议、删除/访问控制和 Sites 平台级存储验证。
2. 只做公开表单：拒绝。用户要求每个人能获得私有建议。
3. 保存邮箱/手机号方便回访：拒绝。与“暂不提供私密信息服务”相冲突。
4. 只在浏览器会话内访问：不足。匿名会话丢失后无法恢复，因此增加高熵回执码。

RISKS

- 用户仍可能在自由文本中主动输入敏感信息；需严格输入提示与服务端启发式拒绝。
- 匿名回执码若泄露，相当于访问凭据；只存哈希、禁止出现在公开日志/URL中。
- 自动建议不能被描述为律师意见、正式机构指示或保证结果。
- 公开日报必须只含聚合值，防止小样本反推个案；必要时对极小类别合并为“其他”。
- Sites 真实调度和数据库能力尚需平台内测试，本地 runner 不等于 Sites 已安装定时任务。

MIGRATION_OR_COMPATIBILITY

旧 v0.7 state 缺少 advisory 字段时自动补空数组，不修改原公司/贡献/审核数据。v0.7.0-rc.1 包与 tag 保持历史不变；v0.7.1 以新分支/候选交付。

VALIDATION

- 领域单测：输入隐私门、回执哈希、权限、日报不泄露正文。
- HTTP 集成：匿名提交→Agent读取→私有建议→回执访问→日报公开→重启恢复。
- 浏览器：真实提交、收到回执、查看建议/日报，console/network/page error 为 0。
- 回归：v0.7 Sites 既有测试、Python 3.9/3.12 基线、Node 103、HTTP 基线。
- 公司研究审计：列明各栏目是否有真实自动来源、队列、复核和发布，不把“有框架”写成“来源覆盖完整”。

ABORT_OR_ROLLBACK_CONDITION

若无法做到“公开日报不含个案内容”“普通用户无法读取他人辅导记录”“回执码不明文存储”“服务端拒绝明显敏感信息”，则本能力不得进入 Sites 候选；回滚为 v0.7.0-rc.1 无匿名辅导入口。

APPROVAL_REQUIRED

用户已在当前会话明确批准新增匿名辅导/代办能力，同时明确要求暂不提供真实私密信息服务。因此本变更可实施；任何未来开放身份证明、敏感附件、健康/支付数据、私人联系方式或自动外部联系均需要新的明确授权与协议。
