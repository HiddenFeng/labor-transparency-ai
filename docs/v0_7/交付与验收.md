# v0.7.2 Sites 大众化 UI / 内容交付与验收

日期：2026-09-15。状态：`LOCAL_SITES_CANDIDATE_NOT_SITES_DEPLOYED`。

## 本轮目标

在不破坏 v0.7.1 业务、隐私和证据合同的前提下，把公开界面从“工程候选/开发者说明页”重构为真正面向普通劳动者的公共服务入口：更容易理解、更有支持感、更有情绪温度，也更明确告诉用户“我遇到了什么、先做什么、可以找谁”。

## v0.7.2 已实现

1. 首页重构为劳动者痛点优先：首页第一屏只突出“匿名求助 / 查看公司记录 / 提交公开线索”三条普通用户主路径。
2. 新增 6 类常见问题导航：工资/加班、工时/休息、合同/离职、安全/工伤、尊重/歧视、组织/发声。
3. 每类问题提供基础的“先记录什么 / 下一步怎么走”说明，并明确具体规则和时限必须回到当地正式渠道。
4. 新增 2026 年公开劳动事件案例区，案例只作教育性引导并链接回原始来源，不自动成为本站事实或证据。
5. 新增外部权益资源目录：ILO、Worker Rights Consortium、ITUC、Workers United、US DOL WHD、OSHA、NLRB、Acas、Fair Work Ombudsman、European Ombudsman 等；明确声明收录不等于合作、隶属、授权或正式转介关系。
6. 公司页新增搜索，并把 E0/E3 等内部证据码翻译为普通人可理解的“未核实线索 / 已核对范围与来源”等标签。
7. 匿名辅导改为支持型叙事和清晰分步表单，但服务端隐私边界不变：仍拒绝真实姓名、私人联系方式、身份证明、家庭详细住址、健康/支付数据和敏感附件。
8. 运营审核入口从主导航降到页脚弱化位置，避免普通用户误解为核心功能。
9. 视觉系统统一为“公共服务 × 公益媒体 × 温暖与力量”：暖白、珊瑚红、深靛蓝、青绿；大字号编辑式标题、少量手写感短句、轻动效、清晰留白。
10. 加入 `:focus-visible`、`prefers-reduced-motion` 和响应式布局；外部链接使用 HTTPS + `noopener noreferrer`。

当前公开案例来自：

- U.S. Department of Labor Wage and Hour Division：2026-08-10 强制培训/会议工时与报复调查；
- U.S. Department of Labor Wage and Hour Division：2026-06-23 overtime/bonus regular-rate 案；
- Worker Rights Consortium：Golden Refit（Bangladesh）调查与补救；
- Worker Rights Consortium：Wah Sun HK Factory（Cambodia）反工会报复调查与补救。

资源导航包括 ILO、WRC、ITUC、Workers United、DOL WHD、OSHA、NLRB、Acas、Fair Work Ombudsman、European Ombudsman 等官方/原始网站。European Ombudsman 页面明确限定为 EU institutions/bodies/agencies 的 maladministration，不被本站描述为私人雇主一般劳动争议入口。

所有这些链接只用于帮助用户寻找正式资源或理解案例，**不表示劳动透明计划与相关组织存在合作关系**。

## 核心业务能力保持

v0.7.1 已验证的完整链路保持：

`公司空间 → 社区参与 → 产品/公司/劳动线索 → E0 → 证据复核 → 独立再分发 → 高证据/公益数据 → 纠错/撤回 → 重审`

匿名辅导链保持：

`去身份化提交 → 一次性回执 → 持久待办 → 受限 Agent 处理 → 私有建议 → 会话/回执查询 → 聚合日报 → 可撤回`

匿名辅导正文仍不会自动转成公司事实、社区热度或公开证据。

## 自动公司研究状态

自动研究仍保持“流程闭环”和“来源覆盖”分开：

- GLEIF 法律实体身份：`AUTOMATED_SUPPORTED`；
- GLEIF 会计合并母公司：`AUTOMATED_PARTIAL`；
- 业务/产品、厂区、完整供应链、劳动条件、官方沟通/申诉渠道：没有完整批准的自动来源覆盖；
- 队列、有限采集、重试/租约/预算/缓存、主体消歧、独立复核、到期发布、通知、SQLite 持久化：已在 Python back office 实现。

所以不能说“系统已经自动搜集公司所有类型信息”。
