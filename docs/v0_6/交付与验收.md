# v0.6 调度、恢复与真实运行门槛：交付及验收

日期：2026-09-14。此文档记录 v0.6 阶段验收；账号隐私迁移后，公开源码现位于 `https://github.com/HiddenFeng/labor-transparency-ai`，原阶段性 GitHub Pages 镜像不再作为当前入口，当前公开交互站点为 `https://workermanifestfellowship.vercel.app`。日常工程、测试、发布准备和公告由项目 Agent 管理。

## 1. 当前已经完成

1. 有限研究调度器、持久心跳、队列健康、逾期通知、发布通知、失败恢复、租约/退避和幂等发布继续有效；真实资料仍必须经过冻结版本与人工复核后才能发布。
2. 公司与产品展示已把“社区好评/差评”和“证据支持的具体劳动实践”分开；公司、产品、劳动实践分别保留自己的证据等级，不把热度当事实，也不因资料缺失阻断社区与私密求助。
3. 用户共建资料与产品、贡献修改/纠错、双人复核后公益再分发、企业代表回应、讨论/条件/私密事项等现有链路保持通过。
4. 修复新机可运行性：不存在的 `uvicorn==0.48.0` 固定版本改为当前可安装的 `0.39.0`；兼容macOS系统Python 3.9的Pydantic类型解析；当系统Python缺少 `hashlib.scrypt` 时使用 `cryptography` 的同参数Scrypt实现，保证账号密码哈希语义不降级。
5. 新增运行数据备份/恢复：SQLite通过官方backup API取得一致快照；私密附件密钥独立复制；目录/文件权限收紧；清单记录SHA-256与SQLite `quick_check`；有私密附件时必须真实解密并核对内容哈希，否则拒绝通过。
6. 新增恢复保护：恢复默认拒绝覆盖，必须显式声明服务已停止；替换已有数据库前先生成安全备份；恢复失败时尝试用安全备份回滚。
7. CI Python范围扩展为3.9与3.13；本机同时实测系统Python 3.9.6和Homebrew Python 3.12.14。
8. 新增独立生产入口 `app.production:app`：配置默认失败关闭，生产数据库必须位于源码目录外；精确Host/HTTPS/Origin、Secure+HttpOnly+SameSite会话、会话绑定CSRF、持久限流、最小安全审计及安全响应头均已接入。默认本地入口仍保持原有回环边界，两种模式不会自动混用。
9. 新增生产附件安全门：生产附件默认关闭；只有显式启用ClamAV且扫描结果为 `CLEAN` 才允许写入加密附件。扫描器缺失、运行错误或判定感染均拒绝保存；扫描状态不改变材料E2/真实性结论。
10. 新增非敏感 `/api/health` 与生产配置预检；提供Caddy、systemd和生产环境变量示例，但这些只是可审查模板，没有安装到真实服务器。

## 3. 当前最大可辩护结论

**已验证：** v0.6具备可重复运行的本地核心平台能力和明显更完整的生产候选运行基线：公司/产品共建展示、私密帮助、有限研究、版本复核、账号与权限隔离、备份恢复，以及精确Host/HTTPS/Origin/CSRF/限流/安全Cookie/审计、管理员精确网络门都存在真实可执行链路；当前Mac还已真实跑通Caddy 2.11.4反向代理、launchd故障恢复与ClamAV 1.5.4/daily签名库的生产附件扫描。

**较强支持但不能扩大：** 当前来源适配器至少在一次真实GLEIF请求中可用，当前桌面与窄视口页面在本机Chrome中可用；真实本机Caddy、launchd和ClamAV证明这些部署机制具备基础可行性。这仍不等于目标生产服务器、正式证书生命周期、长期来源/病毒库更新、容量或全天候运维已经可靠。

**仍不支持：** 交互式后端已经达到生产级公网运营；正式CA续期、DNS、防火墙、目标服务器systemd/容器、Secret Manager、独立管理员身份/MFA、长期FreshClam、异地备份、监控告警和容量门已经完成；真实申诉已经能受控提交。GitHub源码与GitHub Pages只读站点已经上线，这两项不再属于未完成项。

## 4. 当前公开发布边界与后续可选项

当前用户要求“非必要性就不做”，因此不再把完整生产后端运维作为当前公开发布的阻塞条件。源码与只读公益站点已经正式公开，且不接收账号、投稿、私密申诉或真实附件。若未来确有公开交互式后端的实际需求，再按需完成正式CA/DNS/防火墙、目标服务器systemd/容器、Secret Manager/MFA、长期FreshClam、监控告警与异地灾备。

当前仍需长期坚持的不是继续堆基础设施，而是：真实资料不伪造；社区热度与证据等级分离；私密数据不进入公开仓库/站点；公告必须以当前验证证据为准；对外明确项目由AI制作与Agent管理但AI不具有监管、司法或法律代理身份。

项目级Git边界已完成，GitHub公开仓库与Pages站点均已实际上线。后续版本由 `AGENTS.md`、`agents/PROJECT_MANAGER_AGENT.md` 和 `agents/SOCIAL_ANNOUNCEMENT_AGENT.md` 约束Agent持续维护。
