## 中国大陆访问：真实测试结果，而不是推断

当前网络实测显示：

- 账号迁移前的阶段性 GitHub Pages 镜像已经退出当前公开入口，不再用于现项目发布；
- `vercel.app` 在当前大陆网络直接连接超时/不稳定；
- `workers.dev` 在当前大陆网络直接连接失败/超时；

为验证真实可行路径，本轮新增正式的 EdgeOne 静态构建 + Edge Function `/api/*` 代理：

```text
大陆访问者
  -> EdgeOne 前端
  -> EdgeOne Edge Function（同源 /api 代理）
  -> Cloudflare Worker
  -> Cloudflare D1
```

匿名 EdgeOne 临时预览已从当前大陆网络真实通过：

- 首页 HTTP 200；
- `/api/health` 经 Edge Function -> Cloudflare Worker 返回 200；

- 页脚显示真实运行版本 `0.8.1-rc.2`，不再出现 `undefined`；
- Edge Function 已改为**缓冲上游响应**并移除 `Content-Length / Transfer-Encoding / Content-Encoding / Connection / Keep-Alive` 等不应透传的响应头，解决早期浏览器 `ERR_INCOMPLETE_CHUNKED_ENCODING`。

## 多源公司资料自动研究

自动公司资料已从 GLEIF 单源扩展到：

- GLEIF：法律实体、LEI、会计合并母公司；
- SEC EDGAR：美国公开公司申报/XBRL（当前部分出口会 403，失败保留为来源缺口）；
- Wikidata：行业、产品/品牌、总部、组织关系、官网等上下文；
- NLRB：案件/charge/petition/representation 记录；
- OSHA：检查/citation 记录；
- DOL WHD：已结案合规行动；
- FMCS：F-7 集体谈判通知、work stoppage；
- DOL OLMS：employer/consultant disclosure；
- USAspending：具体联邦 award / 政府客户关系；
- OpenCorporates / Open Supply Hub：已有 fail-closed adapter，但 token、订阅或许可/关系复核未完成时不会启用。

Cloudflare 线上层在用户新建真实公司后自动创建 `QUEUED` 研究任务，并由 5 分钟 Cron 自动采集**来源候选**；前台可展示经过字段裁剪的来源状态与少量待核对候选。Python back office 继续执行 `candidate -> source binding -> draft -> independent review -> release`。任何搜索命中都不会自动变成公司事实。

历史生产 Worker 网络测试曾得到 11 条候选、9 个来源可用；本阶段新增的真实 Wrangler+D1 自动计划任务验证则按“用户创建 Starbucks -> `QUEUED` -> `*/5` scheduled consumer -> 安全公开投影 -> 重启恢复”完整执行，最终得到 10 条候选、8/11 来源成功，Wikidata timeout、SEC access denied、USAspending 网络异常均作为明确来源缺口保留。来源可用性会随网络/服务变化，系统不得把历史较好覆盖伪装成当前事实。详见 `qa/v0_8/cloudflare-live-research.json`。

## 仍然不能扩大成的结论

- 不能说“全球所有公司的全部数据已经自动完整收集”；来源覆盖仍受司法区、公司类型、许可、数据公开程度和接口稳定性限制。
- 不能说 Vercel/Workers 直连已经适合中国大陆；当前网络实测恰恰证明它们不能作为大陆主入口。
- 不能把 EdgeOne 默认 `edgeone.cool` 项目域名或历史 preview URL 说成无令牌的大陆永久生产入口；当前大陆直连默认项目域名仍受 preview 授权限制。
- 中国大陆稳定生产服务当前仍未承诺；原因是没有采用经过大陆稳定性/合规验收的本地入口，而不是当前发布仍等待腾讯云账号或支付资料。
