```text
大陆访问者

```

## 多源公司资料自动研究

自动公司资料已从 GLEIF 单源扩展到：

- GLEIF：法律实体、LEI、会计合并母公司；
- SEC EDGAR：美国公开公司申报/XBRL（当前部分出口会 403，失败保留为来源缺口）；
- Wikidata：行业、产品/品牌、总部、组织关系、官网等上下文；
- NLRB：案件/charge/petition/representation 记录；
- OSHA：检查/citation 记录；
- DOL WHD：已结案合规行动；
- FMCS：F-7 集体谈判通知、work stoppage；
- DOL OLMS：employer/consultant disclosure；
- USAspending：具体联邦 award / 政府客户关系；
- OpenCorporates / Open Supply Hub：已有 fail-closed adapter，但 token、订阅或许可/关系复核未完成时不会启用。

Cloudflare 线上层只自动保存**来源候选**；Python back office 才执行 `candidate -> source binding -> draft -> independent review -> release`。任何搜索命中都不会自动变成公司事实。

生产 Worker 网络上对真实 Starbucks 候选测试得到 11 条候选，9 个来源可用、2 个来源失败；失败的来源保持明确错误状态，不会用猜测补齐。详见 `qa/v0_8/public-deployment-v081.json`。

## 现在唯一真正需要用户提供的部署输入

请提供或明确授权一个**项目拥有的自定义域名/子域名**用于 EdgeOne，例如 `labor.example.org`。这不是为了修复代码，而是因为 EdgeOne 默认 `edgeone.cool` 项目域名在大陆访问时要求平台 preview 授权，不能作为无令牌稳定大陆入口。

拿到域名后 Agent 可以继续：

- 将域名绑定到 EdgeOne `labor-transparency-public` 正式项目；
- 完成或给出精确的 DNS ownership / CNAME 变更；
- 根据目标加速区域核对 ICP/服务商资格；
- 把新域名加入 Cloudflare Worker exact Origin allowlist；
- 执行无 preview token 的最终公网 Chrome、API、D1、隐私和大陆网络验收。

如果需要恢复 GitHub Actions/Pages，可另外联系 GitHub Support 处理新账号的账号级 Actions 禁用；这不阻塞当前 Vercel/Cloudflare 全球交互服务和 EdgeOne 自定义域名路线。

## 仍然不能扩大成的结论

- 不能说“全球所有公司的全部数据已经自动完整收集”；来源覆盖仍受司法区、公司类型、许可、数据公开程度和接口稳定性限制。
- 不能说 Vercel/Workers 直连已经适合中国大陆；当前网络实测恰恰证明它们不能作为大陆主入口。
- 不能把 EdgeOne 默认 `edgeone.cool` 项目域名或历史 preview URL 说成无令牌的大陆永久生产入口；当前大陆直连默认项目域名仍受 preview 授权限制。
- 正式 EdgeOne 账号项目虽然已经完成，但在自定义域名、DNS 绑定以及适用的 ICP/服务商资格没有完成之前，仍不能承诺“中国大陆稳定生产服务”。
