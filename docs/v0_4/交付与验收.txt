# v0.4 社区共建与公益数据：交付及验收

日期：2026-09-14。状态：本地开发候选，未完成全项目生产验收，未上传GitHub、未部署ChatGPT Sites，未修改用户Mac。

## 本轮已经实现

专门的公司与产品展示页：社区好评、社区差评、证据支持的正向劳动实践三分区。按7/30/90天及关键词查看，显示参与账号、样本大小、具体主张范围、时段和产品独立证据状态。企业劳动条件不自动成为产品品质认证。

共建入口支持公司资料、产品、关系、劳动主张及产品体验五类，提供表单和批量JSON。用户可不附来源发布E0；可以补充、修订、撤回及提交私密纠错。上传次数与票数不自动提高证据等级。

角色化核验记录：作者不能自证；高证据需范围、时段、实际支持来源与真实性检查；正式认定须有相应依据。修改重置证据及再分发批准，避免旧核验套用新内容。软件验证的是流程条件，不声称独立核实真实企业。

安全再分发独立于证据等级：E0也可在证据状态复核、独立授权和第二人隐私版权审核通过后导出，并继续标记未核实。公开展示不自动授权GitHub镜像。私密案件、原始附件、账号及内部核验资料不进入数据包。

五类JSON/CSV、贡献账本、变更与停止再分发记录、文件哈希清单已经由本地工具生成并测试。运行中的公开数据API会反映修订/撤回；远程仓库自动同步尚未接通。匿名或自愿笔名署名均可，说明贡献的对象、范围、版本和证据状态；不建立可购买的可信度积分。

源码按公益用途公开，禁止商业化和其他非公益用途；数据独立授权，第三方依赖保留原许可。LICENSE是发起人要求的自定义源码可用许可草案，不是OSI开源许可证，尚未经具体法域法律审阅。

## 交付包区别

完整交付包：最新代码、历史演进文件、测试原始日志、升级脚本和离线只读演示。历史说明可能描述旧版本，不代表当前功能已全部完成。

GitHub源码候选：由明确白名单导出，排除运行数据库、附件、密钥、环境配置、备份、字体和个人目录；附SHA-256清单。打包不等于上传，GitHub Actions文件存在不等于远端执行过。

ChatGPT Sites只读站点候选：公开计划、完整白皮书、许可、默认零条真实数据。没有账号、投稿或申诉接口。须由Sites实际接入、保存版本、验证和部署；不假定本地Python/SQLite后台可以直接运行，不编造项目ID、域名或DNS记录。

离线展示页：带虚构公司、产品、票数和示范证据，用于在本机查看展示信息结构。可切换三分区、搜索当前列表、打开条目详情；不联网、不写入、不代表浏览器验收通过，不应作为真实企业榜单上传。

## 本地合并

在独立v0.4包执行：

```sh
python scripts/apply_to_local.py /path/to/labor_transparency_v0_2 --from-version v0.2
```

默认只预检。保留本地修改，发生冲突即停止。实际合并需停旧服务、确认备份，再显式加`--apply --service-stopped`；本轮未对用户Mac执行。新增功能仍按plan/community/assistance由服务端控制，阶段开关不会自动接通未实现的外部能力。
